# ロボットランプ イラスト表示 PoC — 引き継ぎメモ

## 目的

△パネルUI（`p=1`）の操作パネルの横に、ロボットランプ（ボッチャの発射台）のイラストを表示し、以下の3種類のアニメーションで実機の動きを視覚的に表現する。

- ボールの上下移動（`moveHeight` / `setHeightPreset` に連動）
- ランプの左右移動（`moveLR` に連動）
- ボールのリリース（投射、`PIT` クリック時のなげる演出に連動）

## 位置づけ・進め方

- **本体（`RAMP-DEMO.html`、公開デモ）には一切手を入れない。** `RAMP-DEMO.html` を複製した **`RAMP-ILLUSTRATION-POC.html`** で実験する（同じリポジトリ・同じブランチ内の別ファイル）
- 実現できず**頓挫する可能性がある**前提の実験的機能
- **実装が固まったら、改めて `RAMP-DEMO.html` 側に正式な機能として移植する**（このファイルをそのまま本体に据えるのではなく、動作確認できたロジックを本体へ手動で持っていく想定）
- それまでの間、本体側に加えた修正（バグ修正等）はこのファイルへ自動反映されない。本体を修正した場合は、このファイルにも手動で追従するか、都度 `RAMP-DEMO.html` から再度複製し直すこと

## スコープ

- 対象UIは **`p=1`（△パネルUI）のみ**。`p=0`（標準UI、本物のBootstrap/obniz-parts-kits使用）はレイアウト自由度が低く対象外
- `DEMO_MODE`（`d=1`）はこれまで通り。実機（`d=0`）時の挙動・安全ルールは本体と同じ扱い
- device IDは本体と同様、**ダミー（`00000000`）固定を維持**。実IDへの置き換えは絶対に行わない

## 実装方針（検討中・未着手）

- イラストの表示エリア：現在の操作パネル（`.panel`）の横に新設。`.wrap`/`.panel-stage`のflexレイアウトに列を追加する形を想定
- アニメーションのトリガーは、既存の `moveHeight` / `setHeightPreset` / `moveLR` / `PIT` クリック時の処理に、イラスト側の状態更新呼び出しを追加する形（本体のモーター制御・EEPROM等のロジックには影響を与えない、あくまで見た目の追加レイヤーとする）
- イラスト自体はSVGまたはCSSで表現する想定（外部画像・外部CDN依存は追加しない方針。`RAMP-DEMO.html`同様、公開デモとして外部依存を増やさないことを優先する）

## 未確定事項（着手前に決めること）
